# IA & Big Data Learning

Portfolio de aprendizaje y especialización en **Inteligencia Artificial y Big Data**.

Este repositorio recoge ejercicios, prácticas y proyectos desarrollados durante mi formación en Python, análisis de datos, Machine Learning, Inteligencia Artificial y Big Data.

## Objetivos

- Reforzar Python aplicado al análisis de datos.
- Aprender NumPy y Pandas.
- Aplicar estadística y matemáticas a problemas reales.
- Comprender los fundamentos de Machine Learning.
- Desarrollar modelos de regresión y clasificación.
- Aprender técnicas y herramientas de Inteligencia Artificial.
- Trabajar con tecnologías y arquitecturas Big Data.
- Desarrollar proyectos prácticos de IA y análisis de datos.

## Contenidos

| Área | Contenido |
|---|---|
| Python | Fundamentos y programación aplicada |
| NumPy y Pandas | Manipulación y análisis de datos |
| Estadística | Estadística descriptiva y análisis de datos |
| Matemáticas para ML | Probabilidad, vectores y matrices |
| Machine Learning | Regresión, clasificación y evaluación |
| Inteligencia Artificial | Modelos y aplicaciones de IA |
| Big Data | Procesamiento y análisis de grandes volúmenes de datos |
| Proyectos | Proyectos completos de aplicación práctica |
